# showcaseview: 1.x → 2.0.0

2.0.0 renamed most `Showcase` and `ShowCaseWidget` parameters to say what they
affect (target vs tooltip, moving vs scale animation). Apps below 1.0.0 first
need null safety (1.0.0); fix what the compiler reports, then continue here.

Search for the "Before" names; every one is a compile error in 2.0.0.

## `Showcase`

| Before (≤ 1.1.8) | After (2.0.0+) |
|---|---|
| `shapeBorder:` | `targetShapeBorder:` |
| `radius:` | `targetBorderRadius:` |
| `overlayPadding:` | `targetPadding:` |
| `showcaseBackgroundColor:` | `tooltipBackgroundColor:` |
| `contentPadding:` | `tooltipPadding:` |
| `tipBorderRadius:` | `tooltipBorderRadius:` |
| `animationDuration:` | `movingAnimationDuration:` |
| `disableAnimation:` | `disableMovingAnimation:` (2.0.0 also adds `disableScaleAnimation:`, a separate switch for the tooltip's scale-in) |

```dart
// Before
Showcase(
  key: _one,
  description: 'Tap to add',
  shapeBorder: const CircleBorder(),
  showcaseBackgroundColor: Colors.blue,
  contentPadding: const EdgeInsets.all(12),
  overlayPadding: const EdgeInsets.all(4),
  animationDuration: const Duration(milliseconds: 1500),
  child: const Icon(Icons.add),
)

// After
Showcase(
  key: _one,
  description: 'Tap to add',
  targetShapeBorder: const CircleBorder(),
  tooltipBackgroundColor: Colors.blue,
  tooltipPadding: const EdgeInsets.all(12),
  targetPadding: const EdgeInsets.all(4),
  movingAnimationDuration: const Duration(milliseconds: 1500),
  child: const Icon(Icons.add),
)
```

## `Showcase.withWidget`

Same renames for the parameters it keeps (`shapeBorder`, `radius`,
`overlayPadding`, `animationDuration`, `disableAnimation`).

2.0.0 also **removed** these parameters from `Showcase.withWidget`, which
draws its own tooltip: `title`, `description`, `titleTextStyle`,
`descTextStyle`, `showcaseBackgroundColor`, `textColor`, `contentPadding` and
`tipBorderRadius`. Delete them; move the styling into the `container` widget.
`height` and `width` stay required until 5.0.0.

## `ShowCaseWidget`

| Before (≤ 1.1.8) | After (2.0.0+) |
|---|---|
| `autoPlayLockEnable:` | `enableAutoPlayLock:` |
| `disableAnimation:` | `disableMovingAnimation:` (and `disableScaleAnimation:`) |

```dart
// Before
ShowCaseWidget(
  autoPlay: true,
  autoPlayLockEnable: true,
  disableAnimation: true,
  builder: Builder(builder: (context) => const HomePage()),
)

// After (written for 2.x; later releases change `builder`, see
// 2.x-to-4.0.0.md)
ShowCaseWidget(
  autoPlay: true,
  enableAutoPlayLock: true,
  disableMovingAnimation: true,
  builder: Builder(builder: (context) => const HomePage()),
)
```

## Unchanged

`ShowCaseWidget.of(context).startShowCase`, `next`, `previous`, `dismiss`,
`completed`, and the callbacks `onStart`, `onComplete` and `onFinish` keep
their names and signatures.

## Check

`flutter analyze` is clean. Run each tour once: tooltip colors, paddings and
the highlight shape should be what they were before the renames.
