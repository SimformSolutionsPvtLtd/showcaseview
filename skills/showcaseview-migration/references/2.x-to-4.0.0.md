# showcaseview: 2.x → 4.0.0

Two breaking releases. Apply the sections your version is below.

## From < 3.0.0

- Dart SDK constraint is now `>=2.18.0` (3.0.0). Raise `environment: sdk:` in
  the app if it is lower.
- `ShowCaseWidget.builder` changed from `Builder` to `WidgetBuilder`: pass a
  function, not a `Builder` widget. Search for `builder: Builder(`; it no
  longer compiles.
- The default tooltip text now uses `TextTheme.titleLarge` and `titleSmall`
  instead of the deprecated `headline6` and `subtitle2` styles (3.0.0). Nothing
  to change in app code, but a tooltip that relied on the old theme styles may
  look different: check them.

```dart
// Before
ShowCaseWidget(
  builder: Builder(
    builder: (context) => const HomePage(),
  ),
)

// After
ShowCaseWidget(
  builder: (context) => const HomePage(),
)
```

The function still receives a `BuildContext` below `ShowCaseWidget`, so
`ShowCaseWidget.of(context)` calls inside it keep working.

## From < 4.0.0

4.0.0 split text alignment from widget alignment. `titleAlignment` and
`descriptionAlignment` used to take a `TextAlign`; those names now take an
`AlignmentGeometry` (default `Alignment.center`) that positions the title or
description inside the tooltip. The `TextAlign` versions are
`titleTextAlign` and `descriptionTextAlign`.

Passing a `TextAlign` to the old names is a compile error, so search for
`titleAlignment:` and `descriptionAlignment:` and rename the ones that hold a
`TextAlign`:

```dart
// Before (2.0.0 – 3.x)
Showcase(
  key: _one,
  title: 'Menu',
  description: 'Open the menu',
  titleAlignment: TextAlign.center,
  descriptionAlignment: TextAlign.center,
  child: const Icon(Icons.menu),
)

// After (4.0.0+)
Showcase(
  key: _one,
  title: 'Menu',
  description: 'Open the menu',
  titleTextAlign: TextAlign.center,
  descriptionTextAlign: TextAlign.center,
  child: const Icon(Icons.menu),
)
```

Leave a `titleAlignment:` alone when its value is an `Alignment` (it was not
valid before 4.0.0, so it only appears in code already written for 4.x).

## New in 4.0.0, no migration needed

Tooltip actions (`tooltipActions`, `tooltipActionConfig`), the
`globalTooltipActions`, `globalFloatingActionWidget` and
`hideFloatingActionWidgetForShowcase` options of `ShowCaseWidget`, per-step
`floatingActionWidget`, `enableAutoScroll` and `scrollAlignment` on `Showcase`
and `toolTipMargin`. See the `showcaseview-guided-tour` skill.

## Check

`flutter analyze` is clean, and tooltip text is aligned as before (title and
description should still follow the `TextAlign` the app had).
